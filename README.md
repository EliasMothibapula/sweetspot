# The Sweet Spot - Custom Cake Ordering Website

This was my second website project, created one week after passing Introduction to Web and Multimedia Design in Year 2, Semester 2 (2023). I built this for a friend who wanted a simple online presence for their custom cake business.

##  About The Project

The Sweet Spot is a clean, single-page website designed to showcase three main cake categories available by order:
- **Container Cake** - Cakes for all occasions, customizable from a gallery selection
- **Cakecups** - Flavorful mini cakes with personalized ordering options
- **Bento Cake** - Aesthetically designed personalized cakes, fully customizable

##  What I Learned

This project helped me grow as a developer:
- Building a website for a real client (my friend)
- Creating a clean, business-focused design
- Structuring product/service categories
- Adding call-to-action buttons for ordering
- Understanding client requirements and translating them to code

##  Built With
